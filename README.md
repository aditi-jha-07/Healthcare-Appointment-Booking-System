Healthcare Appointment Booking System
====================================

NDA Statement: Healthcare network name and provider numbers are generalised. The application design is authentic.

Client – A healthcare network (anonymised)
Role – Full‑Stack Developer
Duration – 7 months

Problem Statement
Patients struggled to find available slots across multiple clinics. Manual scheduling caused no‑shows and administrative overhead.

Solution
Built a web/mobile booking system with real‑time slot management, automated reminders, and integrated video consultation (WebRTC). HIPAA‑compliant data handling.

Key Features

Multi‑location, multi‑provider availability search

Calendar integration (Google, Outlook)

SMS/email appointment reminders

Secure video calls with Twilio

Patient intake forms and insurance verification

Tech Stack

Frontend: React Native (mobile), Next.js (web)

Backend: Node.js (Express), PostgreSQL, Redis

Video: Twilio Video SDK

Security: JWT, OAuth2, data encryption at rest (AES‑256)

Infra: AWS EC2, RDS, S3, Docker Compose for dev

Outcome

Reduced no‑show rate by 35% via automated reminders

Onboarded 120 providers within 4 months
